# Security and privacy policy

This repository is intentionally public and release-only.

Never commit or upload:
- VYRON source code;
- YouTube channel identifiers or private test-channel names;
- Google account information;
- OAuth access/refresh tokens or client secrets;
- local VYRON databases/state;
- migration/export bundles;
- screenshots or logs containing private operator data.

Only signed application artifacts, checksums/signatures, updater manifests and public release notes belong here.
