# VYRON Releases

Public distribution repository for signed VYRON application releases and updater manifests.

This repository intentionally contains **no source code, no YouTube channel data, no Google account data, no OAuth tokens, no local databases, and no VYRON migration bundles**.

Public contents are limited to:
- signed Windows/macOS installers and updater archives;
- cryptographic signatures and checksums;
- updater manifests;
- public release notes.
